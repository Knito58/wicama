First release of WiCaMa - Wither Cage Materials for Minecraft 26.3 (Fabric).

**Blocks**
- Wither Cage Block (`wicama:building_block_opaque`)
- Transparent Wither Cage Block (`wicama:building_block_transparent`)

**Features**
- Both blocks are in the `minecraft:wither_immune` tag, so the Wither cannot destroy them.
- Blast resistance equals bedrock: explosions and Wither skulls leave the blocks intact.
- Hardness of smooth stone. Any tool that can mine obsidian (diamond tier or better, including modded tools) breaks them at smooth stone speed and gets the drop. Weaker tools are as slow as on obsidian and drop nothing.
- Recipes (yield 4): `C S C / S O S / C S C` for the opaque block, and glass (any glass block) in place of the side stone for the transparent block. C = iron chain, S = smooth stone, O = obsidian.

**Requirements:** Minecraft 26.3, Fabric Loader 0.19.5 or newer, Fabric API, Java 25.
